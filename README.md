# scoop-bucket

Personal [Scoop](https://scoop.sh) bucket.

## Adding this bucket

```powershell
scoop bucket add baurfm https://github.com/baurfm/scoop-bucket
```

## Apps

| App | Description |
|-----|-------------|
| [update](https://github.com/baurfm/update) | Comprehensive Windows dev-environment updater — Scoop, Winget, Chocolatey, npm, pipx, uv, Rust, VS Code extensions, WSL, Azure/Google Cloud CLIs and more. |

```powershell
scoop install baurfm/update
```
